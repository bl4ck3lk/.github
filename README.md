# Community defaults

Shared pull request guidance for repositories owned by this account.

The pull request template asks authors to explain the issue or need, the change,
verification, and how to catch or prevent similar problems. Keep answers brief,
concrete, and in plain language. For changes that fix no existing bug, describe
the relevant risk or assumption checked.

GitHub uses these defaults for public and private repositories without their own
corresponding files. Repository-specific templates take precedence and should
include the same exercise. The defaults take effect from this repository's
default branch; existing PR descriptions are not rewritten.

CLI and API authors must include the exercise when supplying an explicit body.
Templates guide authors; they do not enforce completion.

See [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
