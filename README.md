# Community defaults

Shared pull request guidance for repositories owned by this account.

Keep PR descriptions under 150 words by default: one summary sentence,
**Change**, **Checks**, and **Risk** only when needed. Use plain words and
short sentences. Link to detailed evidence; keep broader lessons in project docs.

These defaults apply from this repository's default branch to repositories
without their own corresponding files. Repository-specific templates take
precedence. Existing PR descriptions are not rewritten.

Use the same brief format when a CLI, API, or coding agent supplies the body.
Follow each destination repository's validation instructions and report only
checks that actually ran.

See [GitHub's documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
